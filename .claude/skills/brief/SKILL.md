# brief — 핵심 요약 한 장

## 무엇을

리포트 결과에서 먼저 볼 항목만 한 장으로 추린다. 화면으로는 `/brief` 이며, 값은 리포트 계산 결과를 그대로 옮긴다.

## 입력

- 주차 키 또는 엑셀 경로. 없으면 저장소 최신 주차, 비어 있으면 `inputs/` 의 샘플을 쓴다.
- 선택: 기준일.

## 순서

1. [app.py](../../../app.py) 의 `week_report(week, today, src)` 로 리포트를 만든다.
2. 지표 네 가지를 뽑는다 — 전체 이수율, 전체 탈락률, 제출·승인(승인 수/대상 수), 먼저 볼 할 일(높음 건수).
3. 핵심 항목 다섯 줄을 만든다 — 집계 과정 수(제외 포함), 리포트 발행 가능 여부, 작년 대비 이상치, 확인 필요 특이사항, 기준일 당일 일정.
4. 막고 있는 항목(미제출·반려 대상)이 있으면 기관명을 함께 적는다.

## 출력

지표 네 가지를 먼저, 그 아래 핵심 항목을 `항목 · 값 · 비고` 세 칸으로 적는다. 마지막 줄에 "조치 필요" 인지 "막는 항목 없음" 인지 한 줄로 맺는다. 화면은 `/brief?week=<주차>&date=<기준일>` 이다.

## 규칙

- 표는 세 칸을 넘기지 않는다.
- 비교 자료가 없어 `None` 인 항목은 "자료 없음" 으로 적는다. 0 으로 바꾸지 않는다.
- 값은 리포트 결과에서만 가져온다. 화면이나 답변에서 다시 계산하지 않는다.
