# 하지 말 것 규칙

## 내용

- 실명·실제 사내 자료를 넣지 않는다. 연습·예시는 가짜 데이터로 만든다.
- 확인하지 않은 값을 결과로 적지 않는다.

## 데이터·파일

- `.env` 와 `data/`, `images/` 는 gitignore 대상이다. `data/` 는 실행 중 생성되는 실제 데이터라 지우면 제출·계정이 사라진다 — 지우거나 덮어쓰지 않는다.
- 이 폴더는 git 저장소가 아니다. 변경 이력을 diff 로 확인할 수 없으니 "방금 바뀐 것" 을 추정하지 말고 파일을 직접 읽는다.

## 코드

- 이수율·탈락률 등 지표를 [feature1_aggregate.py](../feature1_aggregate.py) 밖에서 다시 계산하지 않는다.
- 표의 행 순서와 합계 구분 순서는 **입력에 나온 순서**를 따른다. 정렬을 넣지 않는다 (명세 명시 사항).
- 숫자로 읽지 못한 값을 빈칸으로 지우지 않는다. 원본 그대로 보여준다(`_원본` dict + `app.cell()` / `feature1.num()`) — 진짜 누락과 구분하기 위함이다.
- 사용자 입력을 `e()` (html.escape) 없이 HTML에 넣지 않는다.
- 집계·검증 동작을 `specs/` 명세와 어긋나게 바꾸지 않는다. 바꿔야 하면 명세도 같이 고친다.
