## 목표

여러 훈련기관이 매주 제출하는 교육실적·특이사항·주요일정을, 관리자가 기관별로 승인·확정하면 자동으로 취합·집계·전주 대비 비교·시각화해 **주간 리포트 1건**으로 만들어 주는 App.
반복되는 취합·비교·시각화는 App이 처리하고, 사람은 승인·판단 지점만 맡는다.
결과물은 정형 보고서 양식보다 **수치를 한눈에 확인·비교하는 시각화**에 초점을 둔다. *(발표 피드백 반영)*

## 입력 (App이 받는 재료)

**각 훈련기관이 입력하는 값** — *화면 직접 입력* 또는 *엑셀 파일 업로드*로 제출 (두 경로 모두 같은 검증·표준화 규칙을 통과한다)
- 실적 (**과정별**: 훈련목표인원 · 훈련실시인원 · 훈련수료인원 · 중도탈락자) + 과정 분류(NCS·KECO)
- 특이사항 (기관이 보고한 이슈·비고)
- 주요일정 (개강·종강·점검 등 예정 일정)

> 실적은 기관 단위가 아니라 **과정 단위**로 제출(한 기관이 여러 과정 운영). 기관별·NCS별·KECO별 합계는 App이 자동 집계.

**제출 주기 · 마감**
- 실적 기준: 매주 **일요일**까지의 실적 (그 주의 일요일 = 실적 기준일)
- 제출 마감: 그다음 날 **월요일 18:00**(한국시간) — 월요일이 휴일이면 다음 영업일 같은 시각
- 주차 산정: **ISO 8601 주차**를 쓰고, 어느 주차인지는 **실적 기준일(일요일)**이 속한 주로 정한다. 화면에서 고르는 "몇 월 몇 주차"는 **그 달의 N번째 일요일** 기준이며, 주가 달을 걸치면 기준일 쪽 달을 따른다.

**설정 / 저장소**
- 대상 훈련기관 명단 (이번 주 제출 대상) — 미제출·완료율 계산 기준 · **관리자가 갱신**
- 이상치 플래그 기준 — **작년(전년 동기) 자료 대비 10%p 이상 차이**
- 주차별 저장소 (확정된 주차 데이터 누적 / 전년 동기 자료 포함)
- 식별 기준 — 기관은 **기관명**, 과정은 **기관명 + 과정명**으로 구분한다. 별도 코드(ID)는 두지 않으므로 기관명·과정명 표기를 주차마다 똑같이 써야 하며, 표기가 바뀌면 전주·작년 비교가 끊긴다.

### 입력 데이터 명세 (엑셀 업로드 양식)

한 파일에 3개 시트. 컬럼명·필수 여부는 아래 기준으로 표준화한다.

**시트 1. 실적** *(과정 1개 = 1행)*

| 컬럼 | 필수 | 예시 |
|---|:---:|---|
| 기관명 | ✅ | A기관 |
| 과정명 | ✅ | 스마트팩토리 3기 |
| NCS분류 | ✅ | 기계 |
| KECO분류 | ✅ | 제조 |
| 훈련목표인원 | ✅ | 25 |
| 훈련실시인원 | ✅ | 25 |
| 훈련수료인원 | ✅ | 22 |
| 중도탈락자 | ✅ | 3 |

**시트 2. 특이사항** — 컬럼: 기관명, 과정명, 분류(출결/시설/기타), 내용, 확인필요(Y/N)
**시트 3. 주요일정** — 컬럼: 날짜, 기관명, 구분(개강/종강/점검), 내용

> 시트 이름과 1행 머리글은 위 표기 그대로 써야 한다. 「실적」 시트는 필수, 「특이사항」·「주요일정」은 없어도 된다.
> 컬럼명은 이 명세의 이름(`훈련목표인원`·`훈련실시인원`·`훈련수료인원`)을 문서 전체에서 그대로 쓴다. 화면·리포트에서 줄여 부르지 않는다.
> 이 양식은 연습 단계에서는 가짜 데이터로 채운다. 실제 도입 시 세부 컬럼 조정이 필요하면 이 명세를 먼저 고친 뒤 양식을 다시 배포한다.

### 검증 규칙 (2단계 형식 확인에서 걸러 내는 것)

| 검사 | 내용 | 걸리면 |
|---|---|---|
| 필수값 | 8개 컬럼 중 빈칸 | 해당 행을 **오류 행**으로 표시 |
| 숫자 | 인원 4개 항목이 정수가 아님(문자·소수) | 오류 행 · **원본 값을 지우지 않고 그대로 표시** |
| 음수 | 인원 값이 0보다 작음 | 오류 행 |
| 교차 검증 | 훈련수료인원 > 훈련실시인원 / 중도탈락자 > 훈련실시인원 | 오류 행 |
| 분모 0 | 훈련목표인원 또는 훈련실시인원이 0 | 지표를 **`계산 불가`** 로 표시 |

- 오류 행은 **지우지 않고 표에 남기되** 지표를 계산하지 않고(`검증 필요`) 합계에서 뺀다. 빠진 행 수는 합계 구분마다 `제외`로 함께 표시한다.
- `훈련수료인원 + 중도탈락자 = 훈련실시인원` 은 **강제하지 않는다.** 수료·탈락 어느 쪽도 아닌 훈련 중 인원이 있을 수 있어, 어긋나도 오류로 보지 않는다.

## 단계 (처리)

**A. 기관 단위 반복 — 기관마다 제출·검토·승인**
1. 실적 입력 — 한 기관이 실적·특이사항·주요일정을 **화면 직접 입력 또는 엑셀 업로드**로 제출 *(같은 기관이 다시 내면 덮어쓰고 승인 상태는 '제출'로 초기화된다)*
2. 형식 확인 — 양식·필수항목 누락/오류 점검 *(판정 기준은 위 「검증 규칙」 표)*
3. 표준화 — 항목명·단위·날짜 형식 통일
3-1. **잠정 계산 미리보기** — 업로드 즉시 App이 이수율·탈락률 등을 **자동 계산해 바로 보여줌** *(확정 아님, 승인 전 참고용 · 발표 피드백 반영)*
4. **👁 관리자 승인 (기관 건별)** — 확인·수정 후 승인 *(반려 시 재입력 / 명단 전원 승인되면 B로)*

**B. 모든 기관 승인 완료 후 — 한 번만 실행**
5. 취합 — 승인된 입력을 하나의 통합표로 병합
6. 주차별 저장 — 확정 통합본을 이번 주차로 저장
7. 집계 — 지표 계산: **훈련실적(이수율) = 훈련수료인원 ÷ 훈련목표인원**, 탈락률 = 중도탈락자 ÷ 훈련실시인원. 기관별·NCS별·KECO별 합계도 산출
8. 직전 주차 확인 — 지난 주차 데이터 유무 분기 *(없으면 비교 생략·기준주 저장)*
9. 전주 대비 비교 — 지난 주차를 불러와 증감 산출
10. 특이사항 정리 — 이슈를 항목별로 분류
11. 이상치 플래그 — **과정 단위**로, **훈련실적(수료÷목표)**이 **작년 동기(같은 주차번호) 대비 10%p 이상 차이**면 자동 표시. 작년 과정은 **기관명 + 과정명(끝의 "N기"를 뗀 이름)**으로 맞춘다 — "스마트팩토리 3기" 와 작년 "스마트팩토리 2기" 를 같은 과정으로 본다. 짝을 찾지 못한 과정은 비교에서 빠진다
12. **👁 이상치·증감 확인** — 플래그·증감 해석 확인·판단
13. 시각화 — 누적 자료로 표/그래프 생성 *(첫 주는 단일 주차)*
14. 요약 초안 작성 — 지표·특이사항 요약 문단 초안 (AI 초안)
15. 주요일정 정리 — 일정 표로 정리
16. **👁 문구·톤 최종 확정** — 요약 문구·강조점·톤 확인 후 확정

> 사람이 확인하는 지점: 4단계, 12단계, 16단계.

## 출력 (최종 결과물의 모양)

**초점: 시각화·비교 우선.** 정형 보고서보다 ③ 시각화·④ 이상치 비교를 앞세워, 수치를 한눈에 보고 비교할 수 있게 한다. *(발표 피드백 반영)*

주간 리포트 1건 = 아래 **6개** 구성요소를 묶은 것. 각 요소의 **형식**과 **들어갈 항목**은 다음과 같다.

| 구성요소 | 형식 | 들어갈 항목 |
|---|---|---|
| ① 제출·승인 현황판 | **표** | 훈련기관, 제출 여부, 검토 상태, 승인 상태, 비고 + 표 마지막 줄에 **승인 완료율** |
| ② 통합 교육실적표 | **표** | 훈련기관, 과정명, 훈련목표인원, 훈련실시인원, 훈련수료인원, 중도탈락자, 이수율, 탈락률 |
| ③ 핵심 지표 시각화 | **그래프** | **기관별·NCS별·KECO별 합계** 기본 뷰 + 이수율·탈락률 추이(주차별), 전주 대비 증감(▲▼) |
| ④ 이상치 강조 | **목록** | 대상(기관·과정), 이번 훈련실적, 작년 동기, 차이(10%p↑), 방향 |
| ⑤ 특이사항 요약 | **요약문 + 목록** | 분류(출결/시설/기타), 기관, 내용 요약, 확인 필요 표시 |
| ⑥ 주요일정 정리 | **표(목록)** | 날짜, 기관, 일정 구분(개강·종강·점검), 내용 |

- **기본 그래프 뷰**: 기관별 / NCS별 / KECO별 **인원 합계**(목표·실시·수료·탈락)를 보여줌.
- **구분별 비율 계산**: 구분(기관·NCS·KECO)의 이수율·탈락률은 **그 구분의 인원 합계로 다시 계산**한다. 과정별 비율의 평균(가중평균)이 아니다. 예) 기관 이수율 = 그 기관 수료인원 합 ÷ 목표인원 합.
- **과정별 세부 실적**: 별도 화면에서 과정 단위로 상세 조회(드릴다운).

**다운로드 형식**
- **엑셀(.xlsx)** — 입력값 그대로 받는 파일과 리포트 파일 두 가지를 내려받는다.
- **PDF** — 리포트 화면의 「PDF로 저장(인쇄)」 버튼으로 브라우저 인쇄 기능을 써서 저장한다. 서버가 PDF 파일을 만들어 주는 방식이 아니다.

### 출력 예시 — 2026년 7월 3주차 주간 리포트 (샘플 값)

> *아래 수치는 형식을 보여주기 위한 예시이며 실제 데이터가 아님. 기관명·과정명도 가짜다.*
> 주차 표기: 2026년 7월 3주차 = 실적 기준일 **2026-07-19(일)** → ISO **2026-W29** → 작년 동기 **2025-W29**.

**① 제출·승인 현황판**

| 훈련기관 | 제출 | 검토 | 승인 | 비고 |
|---|:---:|:---:|:---:|---|
| A기관 | ✅ | ✅ | ✅ | — |
| B기관 | ✅ | ✅ | ✅ | — |
| C기관 | ✅ | ✅ | ✅ | 수료인원 정정 후 승인 |
| D기관 | ✅ | ✅ | ✅ | — |
| **승인 완료율** | — | — | **4/4** | **100%** |

**② 통합 교육실적표**

| 훈련기관 | 과정명 | 훈련목표인원 | 훈련실시인원 | 훈련수료인원 | 중도탈락자 | 이수율 | 탈락률 |
|---|---|:---:|:---:|:---:|:---:|:---:|:---:|
| A기관 | 스마트팩토리 3기 | 25 | 25 | 22 | 3 | 88.0% | 12.0% |
| B기관 | 데이터분석 2기 | 20 | 18 | 15 | 3 | 75.0% | 16.7% |
| C기관 | 용접기능사 5기 | 18 | 18 | 17 | 1 | 94.4% | 5.6% |
| D기관 | 제과제빵 1기 | 22 | 20 | 18 | 2 | 81.8% | 10.0% |
| **합계** | — | **85** | **81** | **72** | **9** | **84.7%** | **11.1%** |

> 두 지표는 **분모가 다르다.** 이수율은 목표인원, 탈락률은 실시인원으로 나눈다 — B기관처럼 목표(20)와 실시(18)가 다르면 이수율 75.0% + 탈락률 16.7% 가 100% 가 되지 않는다. 합계 줄도 인원 합계로 다시 계산한 값이다(72÷85, 9÷81).

**③ 핵심 지표 시각화** *(리포트에는 기관별·NCS별·KECO별 그래프로 표시 / 여기선 수치로 대체)*
- 전체 이수율(훈련실적): 84.7% (전주 83.1% 대비 **▲1.6%p**)
- 전체 탈락률: 11.1% (전주 12.4% 대비 **▼1.3%p**)

**④ 이상치 강조 — 과정 단위 훈련실적, 작년 동기(2025-W29) 대비 10%p 이상 차이**

| 대상 | 이번 훈련실적 | 작년 동기 | 차이 | 방향 |
|---|:---:|:---:|:---:|:---:|
| B기관 데이터분석 | 75.0% | 88.0% | −13.0%p | 급감(확인 필요) |

> 작년 짝은 "데이터분석 2기" 의 기수를 뗀 이름으로 찾은 것이다. 짝이 없는 과정은 이 목록에 오르지 않는다.

**⑤ 특이사항 요약**
> 이번 주 전체 이수율은 전주 대비 소폭 상승. 다만 **B기관 데이터분석 과정의 훈련실적(75.0%)이 작년 동기 대비 13.0%p 낮아** 확인이 필요함.
- [출결] B기관 — 중도탈락 3명 중 2명 장기결석 (확인 필요)

## 아직 정하지 않은 것 (2026-07-24 기준)

**규칙을 아직 정하지 않은 것**
- 기관·과정 **고유 코드(ID)** — 지금은 이름 문자열로만 구분해, 기관명이 바뀌거나 과정명이 비슷하면 비교가 끊긴다.
- **반려 사유**와 값 **변경 이력** — 지금은 마지막 제출 시각과 직전 상태만 남고, 누가 무엇을 어떻게 고쳤는지는 남지 않는다.
- 비밀번호 최소 규칙·주기적 변경·2단계 인증·**퇴사 시 권한 회수** 절차.
- 개인정보가 섞여 들어올 때의 처리(현재는 인원 수만 받으므로 해당 없음을 전제로 한다).

**정했지만 아직 화면에 없는 것**
- 제출 마감 **시각(월요일 18:00)** 을 지난 제출 자동 차단 — 지금은 마감 뒤에도 제출이 받아진다.
