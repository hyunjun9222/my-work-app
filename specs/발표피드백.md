# 발표 피드백 정리 (2026-07-22)

> 주간 훈련기관 교육실적 App 발표에서 받은 의견·질문 정리
> 분류: 🟢 기능 추가 · 🔵 방식 변경 · 🟠 예외 처리

---

## 받은 의견

1. **각 훈련기관이 입력하면 자동으로 계산되는 방식이 좋겠다** — 🔵 방식 변경
   - 지금: 관리자 승인 후 일괄 계산 / 의견: 입력 즉시 자동 계산되도록.

2. **자료를 업로드하면 실적 특성별로 대시보드에서 상시 확인할 수 있으면 좋겠다** — 🟢 기능 추가
   - 주간 리포트(정기 산출) 외에, 언제든 특성별로 보는 **상시 대시보드** 추가.

3. **보고서 양식보다 시각화·수치를 한눈에 확인·비교하는 데 초점을 맞추면 좋겠다** — 🔵 방식 변경
   - 결과물의 무게중심을 '정형 보고서'에서 '시각화·비교 중심'으로 이동.

---

## 한눈에 보기

| # | 의견 | 분류 |
|:---:|---|:---:|
| 1 | 입력 즉시 자동 계산 | 🔵 방식 변경 |
| 2 | 특성별 상시 대시보드 | 🟢 기능 추가 |
| 3 | 시각화·비교 중심으로 초점 이동 | 🔵 방식 변경 |

> 공통 방향: **"업로드하면 바로, 상시로, 눈으로 비교"** — 정기 보고서보다 실시간 시각화·비교에 무게.
